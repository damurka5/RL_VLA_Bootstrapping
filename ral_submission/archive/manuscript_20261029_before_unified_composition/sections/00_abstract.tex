\begin{abstract}
A pretrained vision-language-action (VLA) model can produce few successful rollouts when transferred to a new action interface. Sparse rewards then hinder learning, while sequential skill training can erase earlier behavior. We propose a pipeline of dense skill acquisition, binary refinement with balanced self-imitation, and milestone-based full-task composition. Intermediate feedback guides exploration, successful experience consolidates skills, and milestone credit connects them under one instruction. Full-task continuation uses action likelihoods consistent with the sampled continuous commands. We implement the pipeline with a SmolVLA residual controller and LoRA, and examine reward design with OpenVLA-OFT on LIBERO-Spatial. The CDPR controller achieves 70.61\% strict success in simulation. On LIBERO-Spatial, dense feedback reaches 65.3\% success versus 61.7\% with terminal-only reward at the same update budget.
\end{abstract}
