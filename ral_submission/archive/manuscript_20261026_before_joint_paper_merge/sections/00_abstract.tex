\begin{abstract}
Adapting a pretrained vision-language-action (VLA) model to a new embodiment can require learning an action module for the target controller. Sparse task rewards provide little feedback when this module initially produces few successful trajectories. We propose a staged reinforcement learning approach that first uses dense rewards to acquire individual manipulation skills, then refines them with binary success rewards and consolidates successful trajectories through self-imitation. Milestone-based reinforcement learning subsequently composes the skills into a policy conditioned on the complete task instruction. We instantiate this approach with a residual action module over pretrained SmolVLA on a cable-driven parallel manipulator. The adapted controller achieves 61.43\% strict full-task success in simulation development evaluation. A complementary OpenVLA-OFT study on LIBERO supports the use of intermediate task feedback beyond initial skill acquisition, using phase-aware dense rewards with a trained action policy. \assumed{Physical experiments demonstrate complete object manipulation on the target robot.} Together, the studies examine structured intermediate feedback for acquiring and composing skills, while the complete adaptation schedule is evaluated on the cable-driven robot.
\end{abstract}
