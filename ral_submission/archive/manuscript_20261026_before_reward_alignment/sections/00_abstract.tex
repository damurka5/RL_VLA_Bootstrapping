\begin{abstract}
Adapting a pretrained vision-language-action (VLA) model to a new embodiment can require learning an action module for the target controller. Sparse task rewards provide little feedback when this module initially produces few successful trajectories. We propose a staged reinforcement learning approach that first uses dense rewards to acquire individual manipulation skills, then refines them with binary success rewards and consolidates successful trajectories through self-imitation. Milestone-based reinforcement learning subsequently composes the skills into a policy conditioned on the complete task instruction. We instantiate this approach with a residual action module over pretrained SmolVLA on a cable-driven parallel manipulator. The adapted controller achieves 61.43\% strict full-task success in simulation development evaluation. A complementary OpenVLA-OFT study on LIBERO evaluates stage-aware feedback for an already trained manipulation policy. \assumed{Physical experiments demonstrate complete object manipulation on the target robot.} These studies examine a training approach for acquiring and composing manipulation skills when adaptation requires learning new action-producing components.
\end{abstract}
