\subsection{OpenVLA-OFT: Intermediate Feedback on LIBERO}\label{sec:libero_results}
We fine-tune an OpenVLA-OFT-based policy using SimpleVLA-RL and LoRA on LIBERO-Spatial~\cite{libero}. This benchmark uses a conventional serial-arm interface, allowing reward design to be studied separately from learning a new action mapping.

Aggregate runs share a 61.0\% initialization. Each aggregate endpoint uses 300 validation rollouts and the native goal verifier. The primary dense and terminal-only conditions use the same terminal reward weight and update budget. Additional conditions examine mixed-outcome group filtering and phase-only feedback. Table~\ref{tab:libero} states the update budgets and terminal reward weights.

A separate low-success task starts at 2.0\%, measured over 1,000 rollouts. Both conditions in that comparison use the same terminal-outcome group filter.
