\begin{abstract}
A pretrained vision-language-action (VLA) model can produce few successful rollouts when transferred to a new action interface. Sparse rewards then hinder learning, while sequential skill training can erase earlier behavior. We propose a pipeline that uses dense rewards only at the beginning to acquire a base policy for simple skills. Binary refinement and balanced self-imitation consolidate these skills, followed by staged reinforcement learning for the complete multi-stage task. Binary milestones connect the skills without requiring a continuous progress function for every phase of the full task. We compare feedback variants with OpenVLA-OFT on LIBERO-Spatial and test adaptation with a SmolVLA residual controller and LoRA on the CDPR. On LIBERO-Spatial, combined dense and phase feedback reaches 65.3\% success versus 61.7\% with terminal-only reward at the same update budget. The CDPR controller achieves 70.61\% strict success in simulation.
\end{abstract}
