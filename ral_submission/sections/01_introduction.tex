\section{Introduction}\label{sec:introduction}
VLA models provide an ability to perform complex object-manipulation tasks based on images received from cameras on the robot. VLA models are often trained on large manually collected datasets. For example, OpenVLA was pretrained on 970,000 robot demonstrations~\cite{openvla}. Modern approaches use RL to enhance the success rate up to 100\% for pretrained VLA models on selected tasks~\cite{pld}. The base VLA model can be adapted through parameter-efficient fine-tuning. Some VLAs can control even two manipulators in parallel~\cite{openvlaoft}. But what if we need to adapt a VLA model to a dissimilar robot embodiment with different degrees of freedom, such as a cable-driven robot with a gripper suspended by four cables, three translation axes, rotation about the vertical axis, and gripper opening? We need to adapt the part of the VLA which produces actions to the target control space. Changing the number of output channels gives commands the robot can execute, but does not by itself teach the robot to grasp, carry, and release an object. Supervised training requires a dataset even when training only a part of the whole model. But we want to generalize this process instead of creating a new dataset with the same tasks for new robots. Can we use RL algorithms to train a VLA's new action module from scratch? In this work, we adapt the pretrained action expert through LoRA and train a newly initialized MLP residual controller over its outputs.

A newly initialized action module does not initially provide reliable task-directed behavior, which is why using terminal-only rewards will barely give any signal for RL to change weights when successful attempts are rare. At the same time, dense rewards for complex object-manipulation tasks are difficult to design. Before grasping, the robot needs to move toward the object; after grasping, it needs to lift the object away from its initial position. We divide a complex instruction into sequential skills whose progress can be described by a dense reward. RL can produce a useful signal for the model at this point, and we can achieve an acceptable success rate and then increase it with a binary reward~\cite{simplevlarl}. Uniting $n$ skills, each having a conditional success rate $p_i$ given completion of the preceding skills under the same instruction, gives a total success rate $p_{\mathrm{total}}=\prod_{i=1}^{n}p_i$. But each skill used its own text instruction, so we may record the most successful demonstrations of each skill, relabel them under one instruction, and concatenate segments whose ending and starting states are compatible. This method of self-imitation learning allows us to train the composed task using successful skill behavior. Moreover, it aligns with the SimpleVLA-RL pipeline, and we can then enhance the model with a binary reward. The success rates of isolated skills do not directly determine the success rate under the composed instruction, because both the instruction and the states at skill transitions change.

So far, we have success criteria for each skill, and we can increase the availability of a learning signal for GRPO's groups by separating the reward into phases and rewarding completion of each phase. An attempt which lifts the object and then drops it can provide a useful comparison with an attempt which never grasps it, although both fail the complete instruction. In general, such a pipeline may allow us to adapt VLA models to unseen robots by describing each skill without manually generating demonstration datasets. Our experiments use simulation, and the CDPR training also includes scripted and assisted trajectories. We also provide a second robot manipulator, WidowX-200, and clarify our pipeline on it. The reported results therefore concern adaptation without collecting human demonstrations on the target robot, while still using automatically generated supervision.
