1. Что считаем успехом

Политика выбирает действие

\[ u\sim\pi_\theta(\cdot\mid x) \]

Политика задаёт вероятности действий. Обучение меняет эти вероятности через параметры головы.

$x$ — признаки наблюдения и инструкции. $u$ — действие до усечения. $\theta$ — обучаемые параметры.

В этой модели признаки VLA заморожены. Симулятор задаёт старты и проверяет успех. Это постановка RL-only. Ниже числа CDPR иллюстрируют реальные измерения, но его предки включают и автоматически подготовленные данные.

1. Что считаем успехом

Одна попытка даёт ноль или один

\[ Y=\begin{cases}1,&\text{задача выполнена},\\0,&\text{иначе}.\end{cases} \]

Вводим результат одной попытки. Для «положить в миску» единица означает выполнение всего условия успеха.

$Y$ — бинарная награда за эпизод.

1. Что считаем успехом

Средняя награда равна вероятности успеха

Уже знаем$Y\in\{0,1\}$
\[ p=\PP(Y=1)=\newterm{\E[Y]} \]

Добавили усреднение по многим попыткам. Среднее нулей и единиц равно доле единиц.

$p$ — вероятность успеха в одном фиксированном контексте, то есть $p=p_c( heta)$. $\E$ означает среднее.

Если из 100 попыток успешны 30, оценка p равна 0,30.

1. Что считаем успехом

Задача включает разные сцены

Уже знаем$p=\E[Y]$
\[ J(\pi)=\newterm{\E_c}\,[p_c(\pi)] \]

Добавили усреднение по контекстам: объектам, положениям и инструкциям. Получили итоговую метрику.

$c$ — контекст. $p_c$ — успех в нём. $J$ — средний успех на заданном распределении задач.

Распределение контекстов фиксируем. Иначе изменение состава задач можно принять за улучшение политики.

1. Что считаем успехом

У вероятностей здесь три разных уровня

Число J не определяет все p_c. У одной сцены успех может быть 10%, у другой 90%, хотя среднее равно 50%. Кнопка «Обозначения» доступна на каждом слайде.

2. Откуда берётся сигнал GRPO

Сравниваем несколько попыток

\[ Y_1,\ldots,Y_G\in\{0,1\} \]

Из одного контекста запускаем G независимых попыток. Различия между исходами показывают, какие действия стоит повторять.

$G=8$ — размер группы в CDPR и WidowX. Для простоты ниже пример из четырёх. $i$ — номер попытки.

Группа из четырёх попыток: 0, 0, 0, 1.

2. Откуда берётся сигнал GRPO

Вычитаем средний результат группы

Уже знаем$Y_i$
\[ Y_i\newterm{-\bar Y} \]

Добавили среднее группы. Успех получает положительный знак, неудача отрицательный.

$\bar Y=(Y_1+\cdots+Y_G)/G$ — доля успехов в группе.

Для группы 0, 0, 0, 1 среднее равно 0,25. Отклонения: −0,25, −0,25, −0,25, +0,75.

2. Откуда берётся сигнал GRPO

Приводим отклонения к одному масштабу

Уже знаем$Y_i-\bar Y$
\[ A_i=\frac{Y_i-\bar Y}{\newterm{\hat\sigma}} \]

Добавили деление на разброс результатов. Так величина сигнала учитывает, насколько редок исход внутри группы.

$A_i$ — преимущество попытки. Для бинарной группы $\hat\sigma=\sqrt{\bar Y(1-\bar Y)}$.

Пока предполагаем, что в группе есть и успехи, и неудачи. На следующем шаге уберём это ограничение.

2. Откуда берётся сигнал GRPO

Защита от деления на ноль

Уже знаем$A_i=(Y_i-\bar Y)/\hat\sigma$
\[ A_i=\frac{Y_i-\bar Y}{\newterm{\max(\hat\sigma,\epsilon)}} \]

Добавили маленькое положительное число ε. Знаменатель теперь не обращается в ноль.

$\epsilon>0$ — численная защита. Если разброс больше ε, формула остаётся прежней.

Если все результаты равны нулю, числитель тоже ноль. Все преимущества равны нулю.

2. Откуда берётся сигнал GRPO

Одинаковые исходы не дают сравнения

Уже знаем$A_i=(Y_i-\bar Y)/\max(\hat\sigma,\epsilon)$
\[ Y_1=\cdots=Y_G\quad\Longrightarrow\quad\newterm{A_1=\cdots=A_G=0} \]

Если все попытки неудачны, GRPO не знает, какую предпочесть. То же верно для группы из одних успехов.

Нулевая группа даёт нулевой вклад награды в градиент политики.

Это утверждение о сигнале награды. Энтропия, другие потери или накопленный момент оптимизатора могут продолжать менять параметры.

2. Откуда берётся сигнал GRPO

Вероятность встретить хотя бы один успех

Уже знаем$\PP(\text{неудача})=1-p$
\[ P_{\ge1}=1\newterm{-(1-p)^G} \]

Из единицы вычли вероятность того, что все G попыток неудачны.

$1-p$ — вероятность одной неудачи. Степень G появляется из независимости попыток при фиксированном контексте.

2. Откуда берётся сигнал GRPO

Для сравнения нужна ещё и неудача

Уже знаем$P_{\ge1}=1-(1-p)^G$
\[ P_{\rm mix}=1-(1-p)^G\newterm{-p^G} \]

Теперь вычли группы, в которых все попытки успешны. Остались смешанные группы с ненулевыми преимуществами.

$p^G$ — вероятность G успехов подряд. $P_{\rm mix}$ — вероятность информативной группы.

2. Откуда берётся сигнал GRPO

Небольшой рост успеха даёт больше полезных групп

Уже знаем$P_{\rm mix}=1-(1-p)^G-p^G$
\[ P_{\rm mix}=1-(1-p)^8-p^8 \]

Подставили размер группы G = 8. При успехе 3% полезны около 22% групп. При успехе 16% полезны уже около 75%.

2. Откуда берётся сигнал GRPO

Длинная цепочка делает первый успех редким

\[ p_{\rm full}\le\newterm{q^m} \]

Если каждый следующий этап проходит с условной вероятностью не больше q, шансы перемножаются.

$m$ — число обязательных этапов. Независимость этапов не нужна: q ограничивает успех при прохождении предыдущих.

Учебный пример: четыре этапа с условным успехом 10% дают не больше 0,01% полного успеха.

Поэтому начинаем с отдельных навыков, для которых успех достижим чаще.

3. Как получить первые успехи

Плотная награда различает неудачи

\[ R_{\rm dense}=\newterm{-d} \]

Вместо одинакового нуля даём больший балл за меньшее расстояние. Появляется сравнение даже до полного успеха.

$d\ge0$ — расстояние объекта до цели в конце эпизода в этой учебной модели. Это упрощённый пример плотной награды.

Расстояния 10 см и 3 см дают разные награды, даже если для успеха нужно попасть ближе 2 см.

Разные награды дают сигнал для обновления, но сами по себе ещё не гарантируют улучшение.

3. Как получить первые успехи

Порог связывает расстояние с успехом

Уже знаем$R_{\rm dense}=-d$
\[ p=\PP(d\le R_{\rm tol})=\newterm{1-\PP(d>R_{\rm tol})} \]

Ввели радиус допуска $R_{\rm tol}$. Теперь успех означает попасть внутрь этого радиуса.

$R_{\rm tol}>0$ — допуск. Для CDPR допуск по XY: миска 0,057 м, тарелка 0,091 м. Здесь рассматриваем только геометрическое условие.

Для реального захвата или размещения нужно отдельно учесть остальные условия: удержание, отпускание и устойчивость.

3. Как получить первые успехи

Малое среднее расстояние даёт нижнюю границу

Уже знаем$p=1-\PP(d>R_{\rm tol})$
\[ p\ge1-\newterm{\frac{\E[d]}{R_{\rm tol}}} \]

Неравенство Маркова даёт верхнюю границу вероятности промаха. Подставили её в предыдущую формулу.

Если $\E[d]<R_{\rm tol}$, правая часть положительна. Тогда есть успехи для запуска бинарного RL.

Учебный пример с допуском CDPR: среднее d = 0,0285 м и R_tol = 0,057 м дают не ниже 50% для геометрического условия. Среднее d здесь задано, а не измерено.

Плотная цель может предпочитать частые почти-успехи редким полным успехам. Поэтому завершаем обучение по бинарной награде.

3. Как получить первые успехи

Как читать расстояние на числовом примере

Геометрическое условие, не весь strict success

Точка показывает выбранное расстояние. Ступенька меняется у допуска.

Допуски взяты из YAML. Положение ползунка — учебное значение. Реальный strict success дополнительно требует захват, удержанный подъём и корректное отпускание без срыва.

3. Как получить первые успехи

Сначала решаем задачу из лёгких стартов

\[ J_{\rm easy}\ge\newterm{P} \]

Задаём порог P. Усложняем старты только после того, как навык достиг этого уровня успеха.

$J_{\rm easy}$ — успех на текущей ступени. $P$ — порог перехода.

Например, начинаем захват рядом с объектом. Затем постепенно увеличиваем расстояние.

3. Как получить первые успехи

При усложнении часть успеха теряется

Уже знаем$J_{\rm easy}\ge P$
\[ J_{\rm harder}\ge P\newterm{-\Delta} \]

Добавили возможное падение Δ при смене стартов. Даже та же политика хуже справляется с более трудной задачей.

$\Delta$ — верхняя граница падения при переходе. Предполагаем $J_{\rm harder}\ge J_{\rm easy}-\Delta$.

3. Как получить первые успехи

Запас должен быть выше порога возврата

Уже знаем$J_{\rm harder}\ge P-\Delta$
\[ P-\Delta\newterm{\ge D_{\rm back}} \]

Сравнили оставшийся успех с порогом возврата. При этом условии новая ступень не вызывает немедленный откат.

$D_{\rm back}$ — порог возврата на лёгкую ступень. В главе он обозначен D.

При P = 0,45 и Δ = 0,129 остаётся 0,321. Это выше порога возврата 0,30.

Число 0,129 взято из 90-го перцентиля наблюдений CDPR. Это иллюстрация настройки, а не строгая верхняя граница Δ.

4. Как соединить навыки

Успех всей задачи требует успеха обоих этапов

\[ p_{\rm full}=q_1\newterm{q_2} \]

Умножили шанс первого этапа на шанс второго после успешного первого.

$q_1$ — захват в полной задаче. $q_2$ — размещение при условии успешного захвата.

Это правило условных вероятностей. Оно не предполагает независимость этапов.

4. Как соединить навыки

Отдельный навык даёт исходную точку сравнения

Уже знаем$p_{\rm full}=q_1q_2$
\[ q_j=s_j\quad\text{при совпадении условий} \]

Если инструкция, старты и оставшееся время совпадают, этап в полной задаче имеет то же качество, что отдельный навык.

$s_j$ — успех отдельно обученного навыка j. $q_j$ — его условный успех внутри полной задачи.

На следующих слайдах учтём два различия между этими условиями.

4. Как соединить навыки

Итоговая инструкция может изменить поведение

Уже знаем$q_j=s_j\quad\text{при совпадении условий}$
\[ q_j\ge s_j\newterm{-\Gamma_j} \]

Вычли запас на смену инструкции. После «возьми» политика может действовать иначе, чем после «положи в миску».

$\Gamma_j\ge0$ — верхняя граница потери из-за инструкции. Пока старты этапа совпадают.

Обучение на собственных успехах с итоговой инструкцией должно уменьшать этот разрыв. Это нужно проверять.

4. Как соединить навыки

Предыдущий этап оставляет другие стартовые состояния

Уже знаем$q_j\ge s_j-\Gamma_j$
\[ q_j\ge s_j-\Gamma_j\newterm{-T_j} \]

Вычли запас на передачу: реальный захват может оставить объект не там и не так, как тренировочные старты размещения.

$T_j=\TV(\rho_{j-1},\mu_j)$ — различие распределений. $\rho$ — реальные состояния передачи, $\mu$ — старты навыка.

TV лежит от 0 до 1. Она ограничивает, насколько может измениться вероятность события при смене распределения.

4. Как соединить навыки

Нижняя граница вероятности не нужна ниже нуля

Уже знаем$q_j\ge s_j-\Gamma_j-T_j$
\[ q_j\ge\newterm{\bigl(}s_j-\Gamma_j-T_j\newterm{\bigr)^+} \]

Заменили отрицательную оценку нулём. Это делает границу корректной для перемножения.

$a^+=\max(a,0)$. Нулевая граница означает, что эта оценка ничего не обещает.

4. Как соединить навыки

Подставляем границы этапов в полную задачу

Уже знаем$q_j\ge(s_j-\Gamma_j-T_j)^+$
\[ p_{\rm full}\ge\newterm{\prod_{j=1}^{m}}(s_j-\Gamma_j-T_j)^+ \]

Для каждого этапа взяли полученную нижнюю границу и перемножили. Символ ∏ означает произведение.

Каждый навык должен быть достаточно надёжен после учёта инструкции и передачи.

Предполагаются реактивная политика, согласованные этапы и достаточный горизонт. Произведение всё ещё может убывать с числом этапов.

4. Как соединить навыки

Два навыка могут дать стартовый сигнал

Уже знаем$p_{\rm full}\ge\prod_j(s_j-\Gamma_j-T_j)^+$
\[ p_{\rm full}\ge(0{,}5-0{,}1-0)(0{,}7-0-0{,}3)=\newterm{0{,}16} \]

Подставили пример: захват с потерей на инструкции и размещение с потерей на передаче.

Для иллюстрации: при фактическом успехе p = 0,16 смешанными будут около 75% групп размера 8.

Это учебный расчёт из главы, а не измеренная успешность пайплайна. Долю смешанных групп считаем по фактическому p, а не по его нижней границе.

5а. Откуда берётся градиент

Как обучаться по сигналу «успех / неудача»

Композиция навыков дала первые успехи полной задачи. Теперь хотим сделать их чаще: нужно понять, как менять параметры сети по результатам попыток.

  1. Что естьЗаписанные действия, их вероятности и итог Y = 0 или 1.
  2. Что ищемНаправление изменения параметров, которое повышает шанс успеха p.
  3. К чему придёмСреднее обновление с центрированной и нормированной наградой направлено вдоль градиента p.

Сначала докажем это для одного контекста и истинной p. Затем разберём замену p оценкой из восьми попыток. Проверка нужна: знак награды сам по себе ещё не доказывает полезность обновления.

5а. Откуда берётся градиент

Шаг 1: выразить направление роста p через записанные попытки.

Сначала фиксируем, чью вероятность меняем

\[ p=p_c(\theta_0)=\PP_{\pi_{\theta_0}}(Y=1\mid c) \]

Выбрали один контекст c и текущие параметры θ₀. Снова запускаем эту же задачу, меняя только случайные действия политики.

p — истинная вероятность успеха до обновления. Это не доля успехов в случайной группе и не средний J по всем сценам.

Учебное p = 0,25 означает: при многократном повторении именно этого контекста успешна четверть попыток.

В задаче навыка Y проверяет навык. В задаче put_into Y проверяет всю инструкцию. Определение Y фиксируем до вывода.

5а. Откуда берётся градиент

Успех можно записать как сумму по траекториям

Уже знаем$p=\E[Y]$
\[ p(\theta)=\int Y(\tau)\,f_\theta(\tau\mid c)\,d\tau \]

Каждую возможную траекторию взвешиваем по её вероятности. Успешные имеют Y = 1, остальные Y = 0.

$\tau$ — вся попытка. $f_\theta$ — её плотность. Интеграл суммирует варианты непрерывных движений.

Для конечного набора вариантов это обычная сумма: успех варианта × вероятность варианта.

Символ dτ — знак интегрирования, а не расстояние d.

5а. Откуда берётся градиент

Градиент показывает, как менять параметры

Уже знаем$p(\theta)=\int Y(\tau)f_\theta(\tau\mid c)\,d\tau$
\[ \nabla_\theta p=\int Y(\tau)\,\newterm{\nabla_\theta f_\theta(\tau\mid c)}\,d\tau \]

Взяли производную по параметрам сети. Меняются вероятности траекторий, поэтому производная действует на f.

$\nabla_\theta p$ — вектор: одна производная для каждого параметра. Направление этого вектора локально увеличивает p.

Предикат Y и динамика симулятора не зависят от параметров сети. Нужны условия, позволяющие перенести производную под интеграл.

5а. Откуда берётся градиент

Логарифм помогает переписать производную

\[ \nabla_\theta\log f_\theta=\frac{\nabla_\theta f_\theta}{f_\theta}\quad\Longrightarrow\quad\nabla_\theta f_\theta=f_\theta\newterm{\nabla_\theta\log f_\theta} \]

Использовали обычное правило: производная log f равна производной f, делённой на f. Затем умножили обе части на f.

Логарифм здесь нужен для преобразования формулы. Он ещё не меняет цель обучения.

Равенство используем на носителе распределения, где плотность положительна.

5а. Откуда берётся градиент

Подставляем производную обратно под интеграл

Уже знаем$\nabla_\theta f_\theta=f_\theta\nabla_\theta\log f_\theta$
\[ \nabla_\theta p=\int Y(\tau)f_\theta(\tau\mid c)\newterm{\nabla_\theta\log f_\theta(\tau\mid c)}\,d\tau \]

Теперь под интегралом снова есть плотность f. Значит, выражение можно оценивать обычным средним по попыткам политики.

Мы заменили производную вероятности всех траекторий на среднее величин, вычисляемых для записанных траекторий.

Получили формулу, которая раньше появлялась сразу

\[ \nabla_\theta p=\E_{\tau\sim\pi_{\theta_0}}[Y(\tau)\newterm{Z(\tau)}] \]

Свернули интеграл в знак ожидания E. Длинную производную логарифма назвали Z.

$Y$ выбирает успешные попытки. $Z=\nabla_\theta\log f_\theta(\tau\mid c)$ показывает, как сделать конкретную попытку вероятнее. E усредняет их вклад.

Все производные здесь берём в θ₀. E[YZ] — направление изменения параметров, а не сама вероятность успеха.

5а. Откуда берётся градиент

Z складывается из вкладов действий

Уже знаем$Z=\nabla_\theta\log f_\theta(\tau\mid c)$

Вероятности действий вдоль попытки перемножаются. Логарифм превращает произведение в сумму. Части динамики без θ исчезают при дифференцировании.

$u_h$ — записанное действие. $x_h$ — доступные признаки. Для полной задачи CDPR $H\le128$, до 4 действий исполняются за решение.

В реальной реализации учитывается плотность латентного действия и реализованное смещение исследования.

5а. Откуда берётся градиент

Числовой пример: одно правильное движение

Для проверки возьмём простую политику: правильное движение выбирается с вероятностью θ, неправильное с вероятностью 1 − θ.

В этом учебном примере параметр θ сам является вероятностью. При θ = 0,25 получаем Z успеха = 4, Z неудачи = −4/3.

Это игрушечная политика для проверки алгебры. Параметры реальной головы CDPR не являются вероятностями.

Среднее YZ даёт ровно нужную производную

Взвесили оба исхода по вероятности. Неудачный исход исчез из-за Y = 0. Получили производную p(θ) = θ, равную единице.

Единица означает чувствительность: малое увеличение θ на 0,01 увеличивает p на 0,01. Это не утверждение p = 1.

5б. Какую p вычитаем

Шаг 2: проверить, что вычитание среднего сохраняет нужное направление.

Вычитаем вероятность успеха текущей политики

\[ Y-\newterm{p_c(\theta_0)} \]

Это та же p из начала вывода: шанс успеха в выбранном контексте при старой политике. На время вычисления преимущества считаем её фиксированным числом.

При p = 0,25 успех получает 1 − 0,25 = +0,75, неудача 0 − 0,25 = −0,25.

При обновлении не дифференцируем через вычисленное преимущество. В коде истинная p неизвестна: вместо неё используется групповое среднее Ȳ.

5б. Какую p вычитаем

Суммарная вероятность всех траекторий всегда равна единице. Изменение параметров перераспределяет эту массу, не меняя её сумму.

Поэтому среднее направление увеличения вероятности всех возможных траекторий взаимно компенсируется.

5б. Какую p вычитаем

Добавленный член исчезает при усреднении

Уже знаем$\E[Z]=0$
\[ \E[(Y-p)Z]=\E[YZ]\newterm{-p\E[Z]}=\nabla_\theta p \]

Раскрыли скобки и вынесли фиксированную p за знак ожидания. Последний член нулевой благодаря предыдущему слайду.

В числовом примере: 0,25 × (0,75 × 4) + 0,75 × (−0,25 × −4/3) = 0,75 + 0,25 = 1.

Это доказательство использует истинную p. Для Ȳ из той же конечной группы отдельный расчёт будет ниже.

5в. Зачем нормировка и арксинус

Шаг 3: выяснить, как деление на разброс меняет направление и масштаб обновления.

Разброс бинарной награды выражается через p

\[ \sigma_Y^2=\E[Y^2]-(\E[Y])^2=p-p^2=\newterm{p(1-p)} \]

У нулей и единиц квадрат не меняет значение: Y² = Y. Поэтому дисперсия награды равна p(1 − p).

При p = 0,25 дисперсия равна 0,1875, стандартное отклонение σ = √0,1875 ≈ 0,433.

На этих слайдах 0 < p < 1. Если все исходы одинаковы, нормировка без защиты не определена.

5в. Зачем нормировка и арксинус

Преимущество измеряем в единицах разброса

Уже знаем$Y-p$
\[ A=\frac{Y-p}{\newterm{\sqrt{p(1-p)}}} \]

Разделили отклонение от среднего на стандартное отклонение. Знак сохранился, масштаб изменился.

При p = 0,25: A успеха ≈ 0,75/0,433 = +1,732. A неудачи ≈ −0,25/0,433 = −0,577.

Это истинная нормировка для вывода. Практический GRPO использует Ȳ и σ̂ по группе.

5в. Зачем нормировка и арксинус

Нормированный градиент получает положительный множитель

Уже знаем$A=(Y-p)/\sqrt{p(1-p)}$
\[ \E[g]=\E[AZ]=\newterm{\frac1{\sqrt{p(1-p)}}}\nabla_\theta p \]

Знаменатель одинаков для всех попыток фиксированного контекста. Вынесли его из ожидания и применили формулу E[(Y − p)Z] = ∇p.

При p = 0,25 множитель равен 2,309. Он меняет длину ожидаемого вектора, сохраняя его направление.

g — случайный градиент, вычисленный по попытке. E[g] — его среднее по возможным попыткам.

5в. Зачем нормировка и арксинус

Что именно означает «направление роста»

\[ \left.\frac{d}{d\eta}p(\theta_0+\eta\E[g])\right|_{\eta=0}=\newterm{\frac{\|\nabla_\theta p\|^2}{\sqrt{p(1-p)}}}\ge0 \]

Проверили, как меняется p при маленьком шаге вдоль среднего градиента. Скалярное произведение ∇p с самим собой даёт квадрат нормы.

При ненулевом ∇p достаточно малый идеальный шаг увеличивает p. В стационарной точке производная равна нулю.

Большой шаг, шумная группа, Adam, несколько эпох и другие потери требуют отдельного анализа. Эта локальная формула не обещает рост после каждого реального обновления.

5в. Зачем нормировка и арксинус

Ищем функцию с такой производной

Уже знаем$\E[g]=\nabla_\theta p/\sqrt{p(1-p)}$
\[ F\prime(p)=\newterm{\frac1{\sqrt{p(1-p)}}} \]

Хотим описать, какую цель задаёт нормировка. Если найдём F с такой производной, её градиент по параметрам совпадёт со средним обновлением.

F — вспомогательная шкала качества. Она нужна для анализа весов разных p; алгоритм уже может вычислить обновление без неё.

5в. Зачем нормировка и арксинус

Арксинус появляется из обычного интеграла

Уже знаем$F\prime(p)=1/\sqrt{p(1-p)}$
\[ F(p)=\int\frac{dp}{\sqrt{p(1-p)}}=2\int du=\newterm{2\arcsin\sqrt p} \]

Подстановка p = sin²u даёт dp = 2 sin u cos u du. Корень в знаменателе равен sin u cos u, и эти множители сокращаются.

Берём u от 0 до π/2. Константу интегрирования выбрали так, чтобы F(0) = 0.

Правило цепочки возвращает исходное направление

\[ \nabla_\theta F(p(\theta))=F\prime(p)\nabla_\theta p=\newterm{\E[g]} \]

Для одного контекста F строго возрастает вместе с p. Оптимизация F и рост p согласованы по локальному направлению.

Начали с исходов попыток Y и вероятностей действий. Получили среднее направление изменения параметров, которое локально повышает p одного контекста при ненулевом ∇p.

6. Почему обновление ограничивают

Польза шага и сохранение старых навыков

Нашли полезное направление обновления. Но большой шаг меняет действия и посещаемые состояния; при обучении размещению может ухудшиться захват.

  1. Начинаем с локального прогнозаПо старым попыткам оцениваем пользу новых действий.
  2. Учитываем размер измененияВычитаем запас на ошибку прогноза и отдельно контролируем старый навык.
  3. Получим два условияКогда шаг улучшает J и когда политика остаётся близка к эталону.

Усечение PPO ограничивает стимул к большому сдвигу. Теоретические границы требуют контроля фактического изменения распределений на нужных состояниях.

6. Почему обновление ограничивают

Сравниваем вероятность одного действия до и после шага

\[ w=\frac{\newterm{\pi_\theta(u\mid x)}}{\pi_{\rm old}(u\mid x)} \]

Вводим отношение вероятностей. Оно показывает, насколько новая политика чаще выбирает записанное действие.

$w=1$ — вероятность не изменилась. $w>1$ — действие стало вероятнее.

Вес w безразмерный и может быть больше 1. Расстояние всегда обозначаем d, а допуск — R с индексом tol.

6. Почему обновление ограничивают

Преимущество задаёт желательное направление

Уже знаем$w=\pi_\theta(u\mid x)/\pi_{\rm old}(u\mid x)$
\[ \mathcal L=\E[\newterm{wA}] \]

Умножили отношение на преимущество и усреднили по записанным решениям. Эту цель максимизируем.

При $A>0$ выгодно увеличивать w. При $A<0$ выгодно уменьшать w.

6. Почему обновление ограничивают

Усечение ограничивает выгоду от большого изменения

Уже знаем$\mathcal L=\E[wA]$
\[ \mathcal L_{\rm clip}=\E\!\left[\newterm{\min}\bigl(wA,\newterm{\bar w}A\bigr)\right] \]

Добавили усечённое отношение и выбрали меньшую из двух целей. Слишком большой сдвиг в выгодную сторону перестаёт давать выигрыш.

$\bar w=\operatorname{clip}(w,1-\varepsilon_-,1+\varepsilon_+)$. В конфигурации CDPR $\varepsilon_-=0{,}20$, $\varepsilon_+=0{,}28$: полоса от 0,80 до 1,28.

Усечение цели само по себе не гарантирует малое изменение всей политики. Величину фактического шага нужно контролировать.

Сравниваем старую и новую политики на одной задаче, с теми же стартами и тем же критерием. Меняется только поведение.

К старому успеху добавили ожидаемый выигрыш новых действий в состояниях, которые посещала старая политика.

Неравенство Пинскера даёт α² ≤ δ/2. Подставили его в штраф.

Теорема требует максимальную KL. Средняя approx_kl из лога служит диагностикой и не заменяет это условие.

Для сохранения навыка складываем изменения действий вдоль его траекторий.

$\mathcal T$ — старый навык. $\bar\alpha_h$ — средняя TV на его состояниях при старой политике.

Малый шаг на состояниях размещения ничего не обещает про захват, если его состояния не контролируются.

6. Почему обновление ограничивают

Уже знаем$|\Delta J_{\mathcal T}|\le\sum_h\bar\alpha_h$

Взяли эталон в роли старой политики. Пинскер переводит KL в TV — величину изменения распределения действий. При усреднении используем вогнутость корня.

xₕ — средняя KL на шаге h именно на состояниях эталона для сохраняемого навыка. Поэтому $|\Delta J_{\mathcal T}|\le\sum_h\sqrt{x_h/2}$.

Это средняя KL на каждом шаге для оценки сохранения. В границе улучшения предыдущих слайдов δ означала максимальную KL; это разные условия.

6. Почему обновление ограничивают

Второй переход: объединяем H корней

Уже знаем$|\Delta J_{\mathcal T}|\le\sum_h\sqrt{x_h/2}$
\[ \left(\sum_{h=0}^{H-1}1\cdot\sqrt{x_h/2}\right)^2\le\newterm{H}\sum_h x_h/2=\frac{H D_{\rm ref}}2 \]

Применили неравенство Коши: квадрат суммы произведений не больше произведения сумм квадратов. У нас H единиц, поэтому сумма их квадратов равна H.

Обозначили $D_{\rm ref}=\sum_hx_h$. Затем берём корень обеих неотрицательных частей: $\sum_h\sqrt{x_h/2}\le\sqrt{HD_{\rm ref}/2}$.

Так появился корень: 1/2 пришла из Пинскера, H — из суммирования по времени. D_ref — сумма KL по шагам, а не среднее по всей попытке.

Привязка к эталону ограничивает суммарный уход

Уже знаем$|\Delta J_{\mathcal T}|\le\sum_h\bar\alpha_h$
\[ |J_{\mathcal T}(\pi)-J_{\mathcal T}(\pi_{\rm ref})|\le\newterm{\sqrt{H D_{\rm ref}/2}} \]

Подставили сумму корней в границу изменения успеха. Получили предел возможного ухода от фиксированного эталона на любой итерации обучения.

$D_{\rm ref}$ — сумма средних $\KL(\pi_{\rm ref}\|\pi)$ по шагам на состояниях эталона для этого навыка.

Пример: при H = 128 и суммарной D_ref = 0,0001 граница равна 0,08, то есть 8 п.п. Это условный расчёт. Конечный банк успехов не покрывает все состояния эталона.

8. Зачем повторять собственные успехи

Как использовать уже найденные успешные попытки

RL тратит попытки на поиск успеха. Когда успешная траектория уже найдена, можно повторно учиться выбирать её действия и закреплять найденное поведение.

  1. Что сохраняемСобственные успешные траектории старой политики β.
  2. Что изменяемУвеличиваем правдоподобие этих действий под новой политикой θ.
  3. Что обоснуемСвяжем средний рост правдоподобия всех старых успехов с новой вероятностью успеха J.

Связь даёт неравенство Йенсена. Улучшение на конечном банке само по себе ещё не устанавливает нужное среднее по всем успехам.

\[ \frac{\pi_\theta(u_h\mid x_h)}{\pi_\beta(u_h\mid x_h)} \]

Собираем успешные траектории старой политики β. Проверяем, стала ли новая политика чаще воспроизводить их действия.

$\beta$ — параметры политики, собравшей банк. $\theta$ — параметры после самоимитации.

Используем действия, выбранные самой политикой, с известным правдоподобием.

Рост правдоподобия успехов даёт границу улучшения

9. Все величины на примере CDPR

Полный успех можно разложить на два условных этапа

\[ \widehat J_{\rm eval}=\underbrace{\frac{1832}{2048}}_{q_{\rm lift}}\cdot\underbrace{\frac{1416}{1832}}_{q_{\rm finish}}=\newterm{\frac{1416}{2048}} \]

Первый множитель: дошли до удержанного подъёма. Второй: завершили всю инструкцию среди тех попыток, где подъём был.

Это q этапов уже внутри put_into. Они включают фактические последствия инструкции и передачи. Это не s отдельных навыков на специальных стартах.

В коде strict success требует lifted. Поэтому такое разложение верно. Оно не доказывает независимость этапов или сохранение отдельной инструкции pick_up.

9. Все величины на примере CDPR

Просадка одного этапа может компенсироваться другим

\[ q_{\rm lift}^{\rm new}q_{\rm finish}^{\rm new}\ge J_{\rm old}\quad\Longleftrightarrow\quad q_{\rm finish}^{\rm new}\ge\newterm{\frac{J_{\rm old}}{q_{\rm lift}^{\rm new}}} \]

Общий результат сохраняется, если рост второго множителя перекрыл падение первого. Условие получили делением на положительный q подъёма.

При падении q подъёма до 0,81 нужно q завершения ≥ 0,607910/0,81 ≈ 0,7505. Значение 60M, 0,7729, выше этого порога.

Получили бы 0,81 × 0,7729 = 62,61%, выше 40M. Это сценарий с удержанием второго множителя, а не наблюдавшаяся просадка. При q подъёма = 0 полный успех равен нулю.

9. Все величины на примере CDPR

Код защищает сигнал за уже достигнутый этап

\[ A_{\rm used}=A_{\rm stage}+\newterm{\max(A_{\rm full},0)} \]

Для достигнутого подхода или подъёма отрицательный бонус полной задачи обнуляется. Поздняя ошибка не отнимает уже заработанный локальный сигнал.

В запуске CDPR: коэффициент полного бонуса 1, отрицательный масштаб для достигнутого этапа 0, массы трёх стадий одинаковы.

Формула относится к допустимой записи достигнутого раннего этапа. Размещение получает полный сигнал один раз. Весь loss с масками и бонусами не равен идеальному градиенту ∇F(p); гарантии сохранения навыка нет.

Итог и условия

Каждый этап пайплайна решает конкретную проблему

  1. Плотная награда и лёгкие стартыдают первые различающиеся исходы.
  2. RL отдельных навыковповышает качество каждого этапа.
  3. Композиция на собственных успехахсогласует итоговую инструкцию и передачу между этапами.
  4. Бинарный RL полной задачиповышает вероятность строгого успеха.
  5. Смесь навыков и якорь к эталонупомогают контролировать забывание.

Теория объясняет назначение этапов. Их фактический эффект проверяем на целевых стартах и по строгому критерию успеха.
