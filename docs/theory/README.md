Статическая презентация для GitHub Pages: `index.html`. Никакая сборка не нужна.
KaTeX загружается с CDN; графики работают локально в браузере через `interactive.mjs`.

Она сравнивает коэффициент конечного GRPO с полным перебором бинарных групп,
проверяет крайние случаи, производные, точные счётчики, компенсацию и KL-штраф.

## Различия, которые важно сохранить

`p_c` — истинный успех одного контекста обучающей политики, `J` — среднее по контекстам,
`q_j` — условный успех этапа в полной задаче, `s_j` — отдельный навык.
Отношение плотностей действий обозначено `w`, геометрический допуск — `R_tol`.

Измеренные частоты относятся к режиму оценки CDPR и не измеряют обучающие `p_c`.
Симулятор композиции использует точные эмпирические отношения как исходные точки,
но ручные изменения являются сценариями. Симулятор сигнала дополнительно предполагает
однородный контекст; `P_mix(J)` не равно среднему `P_mix(p_c)` для произвольных сцен.
Нижняя граница шага условна: L и sup KL задаются вручную, а не взяты из измерений.

Успех 69.14% относится к линии CDPR с автоматическими учителями в предках.
Он не является доказательством полностью RL-only обучения.
